# Physics Dictionary release

- Expanded the dictionary from 692 to exactly 1,000 unique Physics concepts.
- Increased coverage from 17 to 26 physics chapters.
- Added 308 concepts spanning advanced mechanics, aerodynamics, materials, electronics, photonics, particle physics, plasma, geophysics and medical physics.
- Added formulas, units, aliases, high-interest labels and validated related-term links for the new entries.
- Preserved `/physics-dictionary` search and all permanent `/physics-dictionary/[slug]` pages.
- Preserved Universal Search integration and sitemap generation.
- Updated dictionary metadata and tests to use the 1,000-concept release.
- Added an idempotent expansion script for future maintenance.
