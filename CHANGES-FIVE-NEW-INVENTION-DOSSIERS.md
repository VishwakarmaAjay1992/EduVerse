# Five new invention dossiers

Added five complete, evidence-led invention histories:

- Telephone
- Automobile
- Mechanical Refrigeration
- Transistor
- Programmable Computer

Each dossier includes necessity, prior art, contributors, documented experiments and failures, milestones, engineering principles, component anatomy, later improvements, licensed historical images, consequences, myths, glossary terms, research questions and authoritative source links.

Dedicated concept diagrams were added for all five new inventions so they follow the same visual teaching format as the original collection.

The collection now contains ten unique invention routes and remains automatically integrated with universal search, sitemap generation and related-content navigation.
